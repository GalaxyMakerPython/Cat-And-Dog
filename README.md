# Cat vs Dog Image Classifier

A Convolutional Neural Network (CNN) built with TensorFlow and Keras to classify images as either cats or dogs.

## Results

The model achieved a best validation accuracy of **76.95%** at **Epoch 58**.

* Best validation accuracy: 76.95%
* Best epoch: 58
* Image size: 128 × 128 pixels
* Model type: Convolutional Neural Network (CNN)

## Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Scikit-learn
* Matplotlib
* OpenCV

## How to Run

1. Install the required Python packages:

```bash
pip install -r requirements.txt
```

2. Make sure the dataset is available in the expected location.

3. Open `main.ipynb` in Jupyter Notebook or JupyterLab.

4. Run the cells to train and evaluate the model.

## Evaluation

The project evaluates the model using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion matrix
